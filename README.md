# otkids-audio-generator

כלי אינטרנט קטן שמייצר **פקודה אחת להדבקה בטרמינל** (iPhone / כל מחשב עם Node 16+).
הפקודה מייצרת קובץ שמע (`<id>.wav`) לכל מילה של **אותקידס** באמצעות Gemini TTS, ושומרת אותם בתיקייה `audio/words`.

**הכלי:** https://yakir-hazan.github.io/otkids-audio-generator/

## איך משתמשים

1. פותחים את הקישור, מדביקים מפתח Gemini ולוחצים "העתק את הפקודה".
2. בטרמינל מדביקים ולוחצים Enter (אפשר מכל תיקייה; כדי שהקבצים יישמרו ישר בפרויקט, עומדים קודם בתיקיית הפרויקט).
3. אם משהו נכשל: `node "$HOME/otkids-audio.js"` מאותה תיקייה, והסקריפט ממשיך מאיפה שעצר (קבצים קיימים מדולגים).
4. בסוף מוחקים את הסקריפט כי המפתח בתוכו: `rm "$HOME/otkids-audio.js"`

## מאיפה באה רשימת המילים

הסקריפט מנסה לפי הסדר:

1. `js/content/bank.js` בתיקייה שבה הוא רץ.
2. `<כתובת האתר של אותקידס>/js/content/bank.js` (ברירת מחדל: `https://otkids.vercel.app`), כלומר הגרסה שפרוסה באתר החי.
3. רשימה מוטמעת בדף (צילום של הרשימה ביום הבנייה, עלולה להיות ישנה).

הקובץ `bank.js` נקרא כטקסט בלבד ומנותח בתבנית. שום דבר ממנו לא מורץ כקוד, ומזהים (`id`) שאינם אותיות באנגלית, ספרות וקו תחתון נדחים.
השורה `word source` בפלט אומרת מאיזה מקור נלקחה הרשימה.

## אבטחה

- אין בריפו הזה מפתחות או טוקנים. המפתח נכנס רק בדפדפן שלך, לתוך הפקודה שאתה מעתיק.
- הדף לא שולח שום בקשת רשת, ולא שומר את המפתח בשום מקום.
- הפקודה כוללת את המפתח. אל תעלה אותה לגיט ואל תשלח אותה הלאה.
